# Google ADK Structured Logging Example

This project demonstrates how to implement structured, context-aware logging for the Google Agent Development Kit (ADK). It solves the common challenge of tracing a specific user's interaction through the verbose internal logs generated by the ADK framework.

The script enriches all log messages—including those from deep within the ADK—with session-specific information (`session_id`, `user_id`, `invocation_id`) and sends them to Google Cloud Logging.

## Key Features

*   **Structured Logging:** Sends logs to Google Cloud Logging with custom fields in the `jsonPayload` for easy filtering and analysis.
*   **Context Injection:** Uses a `logging.Filter` to automatically add `session_id`, `user_id`, and `invocation_id` to every log record.
*   **Concurrency Safe:** Leverages `contextvars` to ensure that log context is correctly isolated when simulating multiple concurrent user sessions.
*   **Enhanced Readability:** Prefixes the plain text of each log message with the session ID (e.g., `[session-id=s-001] ...`) for quick visual scanning.

## Prerequisites

*   Python 3.9+
*   A Google Cloud Project.
*   The `gcloud` CLI installed and authenticated (`gcloud auth application-default login`).
*   Permissions to write logs to your Google Cloud project (`roles/logging.logWriter`).

## Setup

1.  **Clone the project** or save the script to your local machine.

2.  **Create a virtual environment:**
    ```bash
    python -m venv .venv
    source .venv/bin/activate
    ```

3.  **Install dependencies:** 
    Install the packages:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Configure Environment:** Create a `.env` file in the same directory as the script and add your Google Cloud project ID:
    ```
    # .env
    GOOGLE_GENAI_USE_VERTEXAI=TRUE
    GOOGLE_CLOUD_PROJECT=<PROJECT_ID>
    GOOGLE_CLOUD_LOCATION=<LOCATION>>
    ```

## How to Run

Execute the script from your terminal:

```bash
python adk_logging.py
```

## Expected Outcome

1.  **In your terminal**, you will see the script start and simulate two concurrent agent interactions. It will finish by printing messages about flushing and closing the logging handler.

2.  **In Google Cloud Logging:**
    *   Navigate to the **Logs Explorer** in your Google Cloud Console.
    *   Query for logs with the log name `projects/your-gcp-project-id/logs/adk-logs`.
    *   You will see log entries from both the application (`app`) and the ADK framework (`google_adk`).
    *   Each log entry will be structured like this:
        *   The **summary line (`textPayload`)** will be prefixed with the session ID:
            ```
            [session-id=s-001] Sending out request, model: gemini-2.5-flash...
            ```
        *   The **`jsonPayload`** will contain your custom context, making it searchable:
            ```json
            jsonPayload: {
              "invocation_id": "e-...",
              "session_id": "s-001",
              "user_id": "user-001"
            }
            ```

This setup allows you to easily filter for all logs related to a single user or session, for example, by using the query `jsonPayload.session_id = "s-001"`.
